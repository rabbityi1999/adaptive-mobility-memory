# 四条件记忆读取：冻结开发实验结果

2026-10-25。Llama-3-8B-Instruct在GPU0完成600名用户、2,400次生成，内外层退出码均为0，独立复算通过。当前没有本批推理进程。本实验是个人／群体记忆开发诊断，不是新增的AgentMove论文分数复现。

结论：在本次共享候选和读取接口下，个人记忆优于群体记忆；固定融合没有超过个人记忆。development中个人／群体事后二选一上限为17%，仅比固定个人的16%高1个百分点，尚不足以支持投入复杂路由。此上限不涉及融合或重新检索，也不能外推为整个研究方向的上限。

## 固定设计与验收

- 400名fit、200名development，每人一条第一验证session查询；两组互斥，各自保留完整分母，没有将2,400个条件输出当独立用户。两组均属开发诊断；1,033名reserve没有新增查询或调用。
- 每人四条件共享48候选、近期最多5条记录、候选类别／距离和显示顺序。个人与群体分别最多12条记忆，固定融合最多各6条。相同上限不等于实际token严格相等。
- 候选检索本身已使用个人和群体信息，条件差异测量的是额外记忆证据。群体记忆只包含截止时刻前的其他用户train事件，排除本人和reserve；个人长期记忆来自本人train、早于验证session。目标不进入提示，不为候选补入答案。
- FP16、batch1、greedy、最多128输出token，输入无裁剪；五个唯一候选ID的严格JSON数组，格式失败保留分母并计错，不重试、不回退。
- 封存代码提交`369ea780fa9fcd4d37a886b2d9e74b9719c4b0c2`。推理期间未改接口、未读中间准确率。完成后使用预先实现的独立复算器校验输入、标签、提示、响应指纹、顺序、解析和固定分母，正常退出。

配置与运行方式见[输入协议](MEMORY_DIAGNOSTIC_V1.md)、[读取接口](MEMORY_READER_V1.md)、[执行与复算](MEMORY_READER_RUN.md)。精确指标、响应指纹、成本见[聚合结果](../reports/memory_reader_results_20261025.json)；私有输出保存在`/mnt/xuyi/memory_reader_run_v1_20261025`，不上传原始轨迹、提示、标签及逐人响应。

## 成本与解释边界

完成2,400次生成，实际输入3,503,121 token、输出67,200 token，运行2,876.40秒（约47.94分钟），峰值GPU分配17,689,284,608 bytes（约16.47GiB）。3次格式失败均纳入成本与分母。无新增WKG调用、路由训练或在线更新。

本轮个人记忆表现高于近期轨迹，但未实施正确／错配／证据删除等机制对照，不能据此宣称可靠利用正确证据的机制已获证实。固定融合把个人条目从12减为6，也可能引入群体证据；其差异不能单独归因于群体干扰。两类记忆实际长度不同且群体存在空源，因此当前结论对应这些完整实现条件。

本轮与旧pilot的样本、候选数和读取方式均不同，不能直接相减声称接口改动导致提升。已完成的AgentMove替换模型基线与本诊断也使用不同查询／输入，不能将16%与旧基线分数作方法胜负比较。没有习惯变化事件标签或按时间连续适应验证，当前不支持习惯变化适应的结论。

## 后续决策

暂不训练复杂个人／群体路由；本批协议和结果保持冻结，不重跑挑分数。下一步优先制定个人记忆证据必要性及融合预算对照：在相同候选、长度和条目预算下区分正确支持信息的作用与个人条目减半的影响。先固定对照、指标与样本边界，再执行；本页不是该新实验的已执行结果。

fit/development现在均已观察，只能继续作为明确标注的开发诊断，不能包装成新独立验证。reserve继续保留，待机制与评价协议确定后再启用。是否仍研究来源选择，取决于后续是否出现更充分且可在预测前识别的互补证据。
