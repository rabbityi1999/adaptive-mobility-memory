论文顺序重建与固定代码的200名用户有178名重叠，但只有22条查询相同；这22条中20条的个人历史session集合也改变。历史以LLM代码使用的前80%为比较口径，未将其误称为DL的70%训练集。将用户门槛改为5虽不改变选中查询及其个人历史，仍可能改变群体图输入池，不能推断模型输出不变。

新脚本逐条复核清单的原始划分标记，并重建选样顺序，与已完成基线的冻结查询清单200/200逐项一致。报告里的规范化选择哈希使用整数二元组紧凑JSON；`frozen_selection_sha256`保留原文件哈希，两者编码不同，不应混比。人工边界检查确认：20段中前10段不足4次签到时，先划分会留下4条合格测试段，先过滤再划分只留下2条，从而改变用户测试资格。

论文表4的112,942条轨迹仍未解释：88,611和81,637都不匹配。该表的统计阶段或作者实际处理仍需证据，不能声称已完成论文数据协议对齐。本核验不含准确率检验、显著性检验或新模型推理。
